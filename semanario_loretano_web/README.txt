# SEMANARIO LORETANO - Página principal

## Estructura
- index.html -> estructura de la página
- style.css -> diseño y responsive
- script.js -> menú móvil, buscador y puntos de portada
- images/logo.png -> coloca aquí tu logo del Semanario Loretano

## Cómo abrir
1. Abre esta carpeta en Visual Studio Code.
2. Coloca tu logo como: images/logo.png
3. Abre index.html con Live Server.
4. Si no tienes Live Server, abre index.html directamente con el navegador.
